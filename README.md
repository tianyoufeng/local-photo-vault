# LocalPhotoVault

本地照片管理应用：桌面应用（Tauri 2 薄壳）+ 内嵌 Web 服务；手机浏览器局域网访问。
原图无损（不压缩、不转码、不修改 EXIF），数据全部留在本机。

## 1. 特性总览

- **原图无损**：上传/拖拽/导入全程字节级保留，SHA-256 去重与校验，下载二进制一致
- **中文界面 · 暗色模式**：图库、详情、相册、回收站、设置全中文
- **局域网访问**：电脑浏览器 + 手机浏览器（扫码）同 WiFi 上传浏览
- **相册 / 标签 / 评分 / 收藏 / 批量操作**：六类筛选、多选批量管理
- **软删除回收站**：30 天保留，可恢复、惰性自动清理
- **全量备份**：单个 `.lpvbackup` 归档（TAR 容器 + manifest.json + SHA-256 清单），支持合并去重/全量覆盖恢复，恢复前自动回滚点
- **30 天备份提醒**：应用内横幅 + 桌面系统通知，间隔可配置或关闭
- **可选上传令牌**：局域网内再上一道 `x-upload-token` 头校验
- **性能**：分片并发上传、缩略图异步队列、游标分页无限滚动、SQLite WAL

## 2. 安装与运行

### 桌面应用（推荐）
```bash
# 开发模式
npm install
npm run dev          # Web 服务 http://127.0.0.1:8787
# 另开终端启动桌面壳（Tauri）
npm run tauri dev
```
生产打包：`npm run tauri build`（sidecar 内嵌 Web 服务，单 exe 运行）。

### 仅 Web 服务
```bash
npm install && npm run build
npm start            # 默认 8787 端口，绑定 0.0.0.0
```

### 便携包（Windows，免安装，可拷贝到其它电脑）
安装包文件在packaging这个文件里面
包内结构：`LocalPhotoVault.exe` + `server\`（内嵌 Web 服务，含 `node.exe`）+ 三个脚本（`启动LocalPhotoVault.bat`、`firewall-allow.cmd`、`网络诊断.bat`）。

- 双击 **`启动LocalPhotoVault.bat`** 即可（会自动做三件事：清理残留旧服务 → 首次运行放行防火墙 8787 → 启动应用）
- 首次运行会弹出管理员确认（UAC），那是为了添加防火墙规则，点「是」即可；之后不再弹
- 手机连不上时，双击 **`网络诊断.bat`**，按它给出的 5 步逐项检查（含本机 IP、端口监听、防火墙规则、网络位置）
- 换电脑使用：整个文件夹拷过去，双击同一个 bat 即可；无需安装 Node.js / 数据库
- 数据默认在 `D:\picture`；若目标机器没有 D 盘，首次启动会进入设置向导让你另选目录

## 3. 首次启动向导

- 自动创建 `D:\picture`（照片根目录）与 `D:\picture\.lpvault`（数据库/配置/缩略图/日志/临时文件）
- 首次访问 `/login` 设置简单密码（会话 Cookie，局域网模型）
- 设置页可随时修改照片根目录；移动过程不复制原图（手动迁移后重新定位即可）

## 4. 局域网访问与手机上传

- 图库顶栏「扫码访问」：手机扫码直达 `/upload` 上传页（二维码=纯 URL，不含任何令牌）
- 也可手动输入 `http://<电脑局域网IP>:8787/upload`
- **上传令牌（可选）**：设置页启用后，手机首次上传输入一次（本机记忆），仅走 `x-upload-token` 请求头，绝不进 URL

### 手机端提示
- 不支持文件夹拖拽；iPhone 从系统相册选择可能被转码压缩，建议选「原图/实际大小」或从「文件」App 选择
- 局域网 HTTP 下 PWA/Service Worker 不可用；手机浏览器无法删除系统相册照片

### 手机连不上？按顺序排查
> 最省事的入口：双击包内 **`网络诊断.bat`**，它会一次列出「本机 IP / 8787 是否在监听 / 防火墙规则是否存在 / 当前网络位置 / 残留进程」，照它末尾的提示逐条处理即可。

1. **确认同一网络**：手机和电脑必须在同一个局域网（电脑连有线也行，但要接在同一路由器下）。手机用流量、或连了访客网络都会连不上。
2. **核对地址**：设置页「局域网与访问」里列出的是本机可用 IP，扫码地址应是 `http://<该IP>:8787`；若电脑有多个网卡，优先用 `WLAN / Wi-Fi` 那一条。
3. **防火墙**：Windows 的「允许应用通过防火墙」是按**程序完整路径**放行的，把文件夹挪个位置（比如从压缩包解压到桌面）旧规则就失效。`启动LocalPhotoVault.bat` 会补一条**按端口（8787）放行**的规则，与安装路径无关；若提示未放行，请重跑一次 bat 并在 UAC 弹窗点「是」。
4. **路由器 AP 隔离**：部分公共/校园 Wi-Fi 开启「客户端隔离」，禁止设备互访——换一个家用路由器，或改用 Tailscale（见第 7 节）。
5. **手机热点的一种特例**：若电脑连的是**手机开的热点**，个别机型/系统会禁止热点主机访问已连接设备，导致手机反而连不上电脑。此时最稳的是让手机与电脑同连一个家用路由器，或改用 Tailscale。
6. **端口被占**：若电脑上有别的程序占用 8787，先关掉；双击 bat 也会自动清理 8787 上的残留旧服务进程。

## 5. 照片管理

- **筛选**：关键词（文件名/标签）、拍摄日期、相机、镜头、标签、相册、评分≥、仅收藏
- **相册**：多对多归属；多选后「复制到相册」（保留原归属）/「移动到相册」（剪切语义）
- **批量**：多选 → 加标签 / 评分 / 收藏 / 加入相册 / 删除（进回收站）
- **回收站**：软删除 30 天，可恢复或彻底删除，过期惰性自动清理
- **拖拽导入**（桌面端）：从资源管理器/内存卡拖文件进窗口，选「复制保留源」或「移动删源」，SHA-256 全程校验

## 6. 备份与恢复

- **备份**：设置页指定目标目录（建议其他磁盘）→ 一键后台备份（进度/暂停/取消/重试）→ 生成 `LocalPhotoVault_YYYY-MM-DD_HHmmss.lpvbackup`
- 归档结构：`manifest.json`（每文件 SHA-256 清单 + DB 快照哈希）+ `db/lpvault.db`（VACUUM INTO 一致性快照）+ `photos/**`（原图字节）+ `thumbnails/**`
- 归档完成后计算整体 SHA-256 并存入备份记录；手机端也可发起备份并下载归档
- **恢复**（仅桌面端）：拖入 .lpvbackup → 校验归档哈希与 manifest → 恢复前自动回滚点 → **合并去重**（跳过已有 SHA-256）或 **全量覆盖** → 每个提取文件复核哈希，不一致即中止并自动回滚 → 可指定新照片根目录
- **提醒**：默认每 30 天横幅提醒 + 系统通知，间隔 30/60/90 天或关闭

## 7. Tailscale 远程访问（推荐，免公网映射）

1. 电脑和手机安装 Tailscale，同一账号登录（组成加密 WireGuard 虚拟局域网）
2. 电脑查看 Tailscale IP：`tailscale ip -4`（100.x 段）
3. 手机浏览器打开 `http://<Tailscale-IP>:8787` 即可远程上传浏览
4. Windows 防火墙若拦截，放行 8787（私有网络配置）
5. **不建议**把 8787 直接映射到公网（认证模型暴露互联网，暴力破解风险）

## 9. Docker（可选）

```bash
docker build -t local-photo-vault .
docker run -d --name lpv -p 8787:8787 -v lpv-data:/data/picture local-photo-vault
```
容器内照片根目录 `/data/picture`（含 `.lpvault`），务必挂载卷以持久化。

## 10. 数据布局与卸载

```
D:\picture\                    照片根目录（YYYY\MM\文件名）
D:\picture\.lpvault\
  lpvault.db                   SQLite（Prisma）
  desktop-token                桌面令牌（恢复/拖拽导入校验）
  thumbnails\**\*.webp         缩略图（可重建）
  tmp\*.part                   上传/导入临时文件（24h 惰性清理）
  logs\lpv-YYYY-MM-DD.log      结构化日志（7 天轮转）
```
**卸载应用不会删除以上任何数据**；重装后重新定位 photoRoot 即可找回全部照片与索引。

## 11. 常见问题

- **iOS 照片被压缩**：从「文件」App 选实际文件，或系统相册选择时选「原图」
- **RAW 预览**：支持 CR2/CR3/NEF/ARW/DNG/RAF 等提取内嵌 JPEG 预览；无内嵌显示占位
- **磁盘满**：剩余空间低于阈值（默认 2GB，Setting `diskMinFreeGB`）拒绝上传并提示
- **日志位置**：`.lpvault\logs\`，含上传成功/失败、磁盘告警、错误事件
